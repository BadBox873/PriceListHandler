# Проверки и внешняя приёмка

## Автоматическая матрица

`python -m pytest -q` выполняет проверки парсера, ограничений, точного экспорта, независимого диффа, записи при сбое, изоляции черновиков, полной истории после перезапуска, bulk-маркеров и Undo, переноса, архива/корзины, словаря, резервирования и Qt-интерфейса. Параметризованные тесты отдельно проверяют недопустимые количества и форматы XLSX.

Локальный итог 19.11.2026: **91 passed**, включая три проверки настоящего прайса. Машинный отчёт настоящих XLSX: [real-price-verification.json](real-price-verification.json).

Тесты реального прайса запускаются при наличии `PRICE_REAL_FILE`. Коммерческий файл не включён в публичные исходники. Без него три проверки настоящего прайса отмечаются как skipped; остальные выполняются на воспроизводимой синтетической книге. Исходные данные не пересохраняются Excel-библиотекой.

Проверенный образец: SHA-256 `71303589b849c5cb397aa733ab21d84aba459e36b06f79362b7c7baecef807eb`; 11 160 товаров; 108 пустых цен; 198 неизвестных остатков; 423 отсутствующих штрихкода. Локально проверено заполнение G4 количеством 20, множество G по всей книге, повторный импорт и очистка заполненной G. Все 13 нетронутых частей OOXML сохранялись побайтово, а XML листа вне явно заданных G оставался идентичным. Экспорт также прочитан openpyxl, который используется только в тестах.

Прямой поиск по настоящему прайсу в локальном окружении: ориентировочно 5–28 мс, включая первый прогрев. Это измерение текущего окружения, а не гарантия на любом компьютере. Поиск и длительные операции основного окна выполняются в фоне.

CI проверяет Linux и Windows Server 2025, строит автономный EXE, запускает portable из пути с кириллицей и пробелами, проверяет установку, запуск установленного EXE, удаление и сохранность пользовательских данных. Успех запуска зафиксирован в приложенных JSON-отчётах и снимках окна. Отдельные результаты тестов публикуются как артефакты Actions.

## Что ещё не подтверждено

- **Реальный обработчик 1С поставщика:** доступа нет; совместимость не подтверждена.
- **Интерактивная Windows 11 пользователя:** runner использует Windows Server 2025. Нужна проверка на целевом компьютере, включая масштабирование и Проводник/Excel.
- **Визуальное открытие настоящего экспорта в Microsoft Excel:** независимое чтение выполнено, но доступного Microsoft Excel в окружении разработки нет.

Эти проверки не заменяются успешной сборкой и не объявляются пройденными.

## Короткая проверка на Windows 11

1. Установить Setup или распаковать Portable. Ожидается русское главное окно без отдельного Python/Excel.
2. Создать заказ из актуального ХИМБЭСТ. Найти `00000016700`, если код присутствует в выбранном прайсе, либо любой известный товар с достаточным остатком. Ввести 20 или допустимое меньшее количество через Enter. Ожидается обновление заказа и фокус в пустом поиске.
3. Повторить ввод, отдельно проверить замену и прибавление. Превышение остатка должно блокироваться с объяснением.
4. Закрыть и открыть программу. Продолжить черновик; Ctrl+Z/Ctrl+Y должны работать по прежней истории.
5. Экспортировать новый XLSX. Убедиться, что оригинал не изменился. Открыть готовый файл в Excel: ожидается исходный вид без предложения ремонта.
6. Повторно импортировать полученный XLSX, изменить одну G и удалить другую позицию. Экспортировать под новым именем.
7. Передать контрольные варианты в **реальный обработчик 1С ХИМБЭСТ**. Проверить коды, количества, изменения и очистки. Только результат этой операции подтверждает совместимость.
8. Проверить бэкап/восстановление на отдельной тестовой копии данных. Ожидается возврат заказов, истории и исходников, защитная копия прежнего состояния.

При ошибке приложить действие, версию программы и код диагностики из окна. Лог находится в папке данных; весь прайс для обычной диагностики не требуется.
