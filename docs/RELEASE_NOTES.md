Предварительный выпуск **v1.0.0-rc.2** для проверки PriceListHandler на рабочем компьютере и в обработчике 1С поставщика. Он не означает завершённую внешнюю приёмку v1.0.

В этом кандидате готовые EXE проверяются в обычном графическом режиме Windows, с контролем наличия латинских и кириллических глифов. Исправлен режим Windows-снимков: прежний безэкранный backend не предоставлял системные шрифты.

**Скачать:** `Setup-x64.exe` — установка с выбором папки и деинсталлятором; `Portable-x64.zip` — распаковать целиком и запустить EXE. Python и Excel для запуска не нужны. Данные двух вариантов независимы; установщик сохраняет черновики после обычного обновления или удаления.

Реализованы поиск с вводом количества, проверки остатков, импорт заполненного заказа, предпросмотр «было → станет», точечный экспорт XLSX, черновики и история Undo/Redo, массовая вставка и словарь, перенос на новый прайс, архив/корзина, история экспортов, резервирование и темы. После записи XLSX проверяется повторно: меняются только ожидаемые товарные G; остальные части сохраняются.

Настоящий прайс на 11 160 товаров проверен локально. Тесты включают заполнение, изменение и очистку G, сохранность остальных данных, сбои записи/проверки, перезапуск истории и восстановление копий. Сборки проверяются готовым EXE, установкой/удалением на Windows Server 2025 runner и путями с кириллицей/пробелами. JSON-отчёты запуска, снимки окна и SHA-256 приложены.

**Требует внешней проверки:** совместимость с реальным обработчиком 1С поставщика и интерактивная приёмка на пользовательской Windows 11. Эти проверки не объявляются пройденными. Перед рабочей отправкой поставщику проверь контрольный заказ.

Для переноса нужен незаполненный новый прайс; заполненный импортируется отдельным черновиком. Поддерживается один лист с проверенными заголовками A:G; формулы в товарных G, дубли кодов и изменённые колонки блокируются. Сборки без цифровой подписи.
