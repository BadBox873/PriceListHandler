# PriceListHandler

Настольная программа для Windows 11 x64: поиск товаров в прайсе ХИМБЭСТ, составление заказа и экспорт нового XLSX. Python и Excel для запуска готовых сборок не нужны.

Первый распространяемый выпуск — **v1.0.0-rc.1**, предварительная сборка для внешней приёмки. В окне и именах программных пакетов используется базовая версия 1.0.0.

**Исходный прайс не перезаписывается.** Программа точечно меняет значения товарных ячеек столбца G «Заказано», повторно открывает результат и проверяет сохранность остальных данных. XML листа целиком не пересобирается.

**Совместимость с реальным обработчиком 1С поставщика пока не подтверждена.** OOXML-проверка и чтение независимой библиотекой не заменяют приёмку в 1С. Windows-сборки проверяются на Windows Server 2025 runner; интерактивная приёмка на пользовательской Windows 11 остаётся отдельной проверкой.

## Скачать и запустить

Готовые файлы находятся в [GitHub Releases](https://github.com/BadBox873/PriceListHandler/releases).

- **Setup-x64.exe** — установщик с выбором папки, ярлыками и штатным деинсталлятором. Данные сохраняются в `%LOCALAPPDATA%\PriceListHandler` и остаются после удаления программы.
- **Portable-x64.zip** — распакуй всю папку и запусти `PriceListHandler.exe`. Данные хранятся в `Data` рядом с EXE. Переноси вместе с ней; `portable.flag` должен оставаться рядом с EXE.
- **SHA256SUMS.txt** — контрольные суммы установщика и архива.

Не запускай EXE прямо из ZIP. При обновлении portable замени программные файлы, сохранив `Data`. Два варианта используют независимые базы. Сборки без цифровой подписи.

## Работа с заказом

1. Нажми **Новый заказ**, выбери XLSX и назови черновик. Если G заполнен, выбери импорт всего заказа либо отмену открытия.
2. Найди товар названием, кодом или штрихкодом. Слова можно вводить в любом порядке. В колонке **Заказать** введи целое количество и нажми Enter. Поиск очистится, фокус вернётся в него.
3. При повторном вводе выбери **Заменить** или **Прибавить**. Неизвестный остаток и превышение остатка блокируются. Без цены заказ разрешён, сумма отмечается неполной.
4. Исправляй количество в текущем заказе. **Удалить позицию** очищает итоговую G, включая импортированный заказ. Ctrl+Z / Ctrl+Y отменяют и повторяют действия; история переживает перезапуск.
5. Для списка из Excel или письма открой **Массовая вставка**. Проверь разбор, выбери сомнительные товары вручную, явно разреши дубли и выбери замену/прибавление. Ошибочные строки сохраняются для исправления.
6. **Новый прайс** переносит заказ с предпросмотром новых цен и остатков. Совпадение уникального кода основное; изменённый код подтверждается вручную. Количества самовольно не уменьшаются.
7. Открой **Предпросмотр и экспорт**, проверь «Было G → Станет G» и сохрани новый XLSX. После проверки заказ уйдёт в архив. Файл и папка открываются только по нажатию.

Черновики, архив и корзина поддерживают поиск по имени заказа и его товарам, даты и сортировку. Восстановление архива создаёт новый черновик, сохраняя архивную запись. Корзина автоматически не очищается. История экспортов хранит метаданные и путь, без дополнительных копий готовых XLSX.

## Данные и резервирование

Локальная SQLite-база и побайтовые исходные XLSX находятся в папке данных. Изменения записываются транзакционно. Один экземпляр программы блокирует повторное открытие своего хранилища.

Ежедневная копия создаётся при первом запуске за день, если данные изменились. Хранятся 10 последних проверенных обычных копий. В настройках можно выбрать другую папку, создать копию вручную и восстановиться с предварительной проверкой. Перед восстановлением создаётся отдельная защитная копия, которая не участвует в автоматической ротации.

Включаются заказы, история, незавершённые вставки, архив, корзина, словарь, настройки и исходные прайсы. При восстановлении исходники устанавливаются до атомарной замены базы. Прерванное восстановление не вызывает автоматической подмены данных; защитная копия доступна для ручного отката.

Диагностика: `diagnostics.log` в папке данных, без копирования всего прайса. Сеть нужна для необязательной проверки обновлений GitHub. Недоступность сети не мешает заказам; автоматической установки обновлений нет.

## Поддерживаемый формат

Один лист, заголовки A1:G1: `Номенклатура`, `Характеристика`, `Код`, `Штрих-код`, `Спец. цена`, `Остаток`, `Заказано`. Товар определяется строковым кодом C; категории и итог не редактируются. Цена и остаток — числа либо пустые значения. Товарная G должна существовать и не содержать формул. Неизвестные части пакета сохраняются; неоднозначные листы, дубли кодов, переставленные колонки и опасный XML блокируются.

Новый прайс с заполненным G импортируется отдельным заказом. Для переноса существующего заказа нужен незаполненный новый прайс, чтобы не потерять содержащийся в нём другой заказ.

Коммерческий прайс пользователя не включён в публичный репозиторий. Проверенная SHA-256: `71303589b849c5cb397aa733ab21d84aba459e36b06f79362b7c7baecef807eb`. Проверено 11 160 товаров, 108 пустых цен, 198 неизвестных остатков, 423 отсутствующих штрихкода. Два кода с хвостовыми пробелами сохраняются как исходные строки.

## Разработка и сборка

Python 3.12+, PySide6, SQLite, defusedxml:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m pytest -q
python run.py
```

Для настоящего прайса задай `PRICE_REAL_FILE` полным путём к XLSX. Без него три проверки реального файла пропускаются, остальные используют воспроизводимую синтетическую книгу.

```powershell
python scripts/build_windows.py
```

Нужны Windows x64 и Inno Setup 6. В `release` появятся installer EXE, portable ZIP и SHA-256. GitHub Actions тестирует Linux/Windows, собирает версии, запускает готовый EXE в кириллических путях с пробелами, устанавливает/удаляет приложение с контролем сохранности данных. Обычный push создаёт проверяемые артефакты. Явно помеченный `[candidate]` коммит после всех проверок публикует предварительный v1.0.0-rc.1 для приёмки. Стабильный выпуск требует отдельного тега `v*`.

Отдельная проверка экспорта:

```powershell
python scripts/verify_xlsx.py "Прайс.xlsx" "Заказ.xlsx" --report "Проверка.json"
```

Скрипт сравнивает заданные исходник и итог, все неизменяемые части и XML вне разрешённых G. Служебные листы и отчёты в заказ не добавляются.
